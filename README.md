# Combinatoria algebraica

Contar con álgebra: el anillo de series formales, el método simbólico, particiones y q-análogos, la enumeración de Pólya, funciones simétricas y de Schur, tablas de Young, RSK y la fórmula del gancho, la función de Möbius de un orden parcial, matroides y polinomios de grafos, con las demostraciones completas.

**Ver en línea:** https://aaramirez.github.io/mate-combinatoria-algebraica/
